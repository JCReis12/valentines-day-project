"# Projeto de Dia dos Namorados

> Local host: http://localhost:8000

Uma página web romântica criada para celebrar um relacionamento com uma experiência visual e emocional, inspirada em um álbum de memórias, uma linha do tempo e uma carta de amor.

## Sobre o projeto

Este projeto foi desenvolvido como uma homenagem ao amor, com foco em criar uma interface acolhedora, delicada e memorável. A página reúne elementos como:

- galeria de fotos com carrossel
- contador de tempo do relacionamento
- linha do tempo da história do casal
- carta de amor personalizada
- visual elegante com tema em tons suaves e delicados

## Objetivo

O objetivo principal é proporcionar uma experiência especial para a pessoa amada, permitindo revisitar momentos importantes, celebrar a história compartilhada e transmitir sentimentos de carinho, saudade e eternidade.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Estrutura do projeto

- index.html: estrutura principal da página
- style.css: estilos e layout visual
- script.js: interações, slider e contador
- img/: imagens e elementos visuais
- docs/: documentação e materiais de referência

## Como visualizar localmente

1. Abra a pasta do projeto no navegador ou em um editor.
2. Inicie um servidor local, por exemplo:
   python -m http.server 8000
3. Acesse no navegador:
   http://localhost:8000

## Observação

Este é um projeto de caráter pessoal e sentimental, pensado para ser uma lembrança bonita e um presente digital para celebrar um amor."
